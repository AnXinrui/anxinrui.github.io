# anxinrui 博客使用指南

个人博客站点：https://anxinrui.github.io/

基于 [Fuwari](https://github.com/saicaca/fuwari)（Astro 5 + Svelte + Tailwind）搭建，包管理器固定使用 **pnpm**。

---

## 环境要求

| 工具 | 版本 |
|------|------|
| Node.js | >= 20（CI 使用 22） |
| pnpm | >= 9（项目锁定 `pnpm@9.14.4`） |

未安装 pnpm：

```bash
npm install -g pnpm
```

---

## 启动项目

### 1. 安装依赖

```bash
cd anxinrui.github.io
pnpm install
```

> 项目 `preinstall` 会禁止用 npm / yarn 安装，请只用 pnpm。

### 2. 本地开发

```bash
pnpm dev
```

浏览器打开 http://localhost:4321 ，改代码会自动热更新。

### 3. 其他常用命令

| 命令 | 作用 |
|------|------|
| `pnpm build` | 构建静态站点到 `dist/`，并生成 Pagefind 搜索索引 |
| `pnpm preview` | 本地预览构建结果 |
| `pnpm check` | Astro 类型与内容检查 |
| `pnpm new-post <名>` | 创建新文章 |
| `pnpm new-moment <名>` | 创建新碎碎念 |
| `pnpm format` | 格式化 `src/` 代码 |
| `pnpm lint` | Biome 检查并自动修复 |

### 4. 部署

推送到 `main` 分支后，GitHub Actions（`.github/workflows/deploy.yml`）会自动构建并发布到 GitHub Pages。

> **不要用 Jekyll 部署。** 仓库 Settings → Pages → Build and deployment → Source 必须选 **GitHub Actions**，不要选 Deploy from a branch。项目已在 `public/.nojekyll` 禁用 Jekyll 处理，避免 `_astro` 等目录被忽略。

## 写文章

### 快速新建

```bash
pnpm new-post my-article
```

会在 `src/content/posts/` 下生成带 front-matter 的 Markdown 文件，例如 `my-article.md`。

也支持子目录写法：

```bash
pnpm new-post my-article/index
# 生成 src/content/posts/my-article/index.md
```

### Front-matter 字段

```yaml
---
title: 文章标题
published: 2026-07-03
description: 摘要，显示在首页卡片上
image: ./cover.jpg          # 可选，封面图
tags: [标签一, 标签二]
category: 分类名
draft: false                # true = 草稿，不会公开显示
---
```

| 字段 | 说明 |
|------|------|
| `title` | 标题 |
| `published` | 发布日期 |
| `description` | 摘要 |
| `image` | 封面图路径（见下文「图片处理」） |
| `tags` | 标签数组，建议用中文 |
| `category` | 分类，建议用中文 |
| `draft` | `true` 时不展示 |

### 推荐目录结构

**方式 A：单文件**

```
src/content/posts/
└── my-article.md
```

**方式 B：文章 + 配图放同目录（推荐）**

```
src/content/posts/
└── my-article/
    ├── index.md
    ├── cover.webp
    └── diagram.png
```

`index.md` 里封面写 `image: ./cover.webp`，正文插图写 `![说明](./diagram.png)`。

### Markdown 扩展

站点已内置以下能力，详细示例见 `src/content/posts/fuwari-guide.md`：

- **提示块**：`:::note` / `:::tip` / `:::warning` / `:::important` / `:::caution`
- **GitHub 卡片**：`::github{repo="owner/repo"}`
- **剧透**：`:spoiler[隐藏内容]`
- **数学公式**：行内 `$...$`，独立 `$$...$$`
- **代码块**：Expressive Code（`title=`、`del={}`、`ins={}`、`showLineNumbers` 等）
- **视频**：直接粘贴 YouTube / Bilibili 的 `<iframe>` 到正文

### 关于页

编辑 `src/content/spec/about.md`，对应 `/about/` 页面。

### 站点配置

| 改什么 | 文件 |
|--------|------|
| 标题、Banner、主题色、导航、头像 | `src/config.ts` |

## 写碎碎念

碎碎念用于记录短文字和生活碎片，支持多图配图，展示在 `/moments/` 页面，按时间倒序排列，支持底部分页。

### 快速新建

```bash
pnpm new-moment 2026-07-03-随想
```

会在 `src/content/moments/` 下生成目录，例如 `2026-07-03-随想/index.md`。

### Front-matter 字段

```yaml
---
published: 2026-07-03T20:30:00+08:00
images:
  - ./photo1.webp
  - ./photo2.webp
draft: false
---
```

| 字段 | 说明 |
|------|------|
| `published` | 发布时间（北京时间），格式 `2026-07-03T20:30:00+08:00` |
| `images` | 配图列表，可选，路径相对于碎碎念目录 |
| `draft` | `true` 时生产环境不展示，本地 dev 可见 |

碎碎念**不需要** `title`、`tags`、`category`，正文直接写 Markdown。

### 推荐目录结构

```
src/content/moments/
└── 2026-07-03-随想/
    ├── index.md
    ├── photo1.webp
    └── photo2.webp
```

`index.md` 示例：

```yaml
---
published: 2026-07-03T20:30:00+08:00
images:
  - ./photo1.webp
  - ./photo2.webp
draft: false
---

今天天气不错，随手拍了两张。

比博文**短**就行，不用写标题。
```

### 纯文字碎碎念

不需要配图时，`images` 留空数组即可：

```yaml
images: []
```

### 博文 vs 碎碎念

| | 博文 | 碎碎念 |
|---|---|---|
| 命令 | `pnpm new-post` | `pnpm new-moment` |
| 目录 | `src/content/posts/` | `src/content/moments/` |
| 页面 | 首页 + 独立文章页 | `/moments/` 时间线 |
| 需要标题 | 是 | 否 |
| 适合 | 长文、教程 | 碎碎念、短动态、配图 |

### 发布碎碎念

```bash
pnpm dev    # 预览 http://localhost:4321/moments/
git add .
git commit -m "feat: 新增碎碎念"
git push    # 推 main 后自动部署
```

## 图片处理

### 三种引用方式

| 方式 | 路径写法 | 文件放哪 | 适用场景 |
|------|----------|----------|----------|
| 相对路径 | `./cover.webp` | 与文章/碎碎念同目录 | **封面、插图、碎碎念配图（推荐）** |
| 站点资源 | `assets/images/xxx.webp` | `src/assets/images/` | Banner、头像、全站共用图 |
| 静态资源 | `/images/xxx.webp` | `public/images/` | 不需 Astro 优化的固定文件 |
| 外链 | `https://...` | 不存本地 | 临时引用、图床 |

### 封面图（front-matter `image`）

```yaml
image: ./cover.webp
```

图片与文章放同一目录，构建时会走 Astro 图片优化（`sharp`），并用于首页卡片、文章页顶部 Banner。

也支持：

```yaml
image: https://example.com/cover.jpg   # 外链
image: /images/cover.jpg                 # public 目录
```

### 正文插图

与文章同目录时，直接用 Markdown 语法：

```markdown
![架构示意图](./architecture.png)
```

正文图片支持 **PhotoSwipe 点击放大**（光标为放大镜样式）。

### 碎碎念配图

在 front-matter 的 `images` 字段列出文件名，图片放碎碎念同目录：

```yaml
images:
  - ./photo1.webp
  - ./photo2.webp
```

1 张图大图展示，2 张并排，3 张及以上九宫格排列。碎碎念配图同样支持点击放大。

### 全站图片（Banner / 头像）

放在 `src/assets/images/`，在 `src/config.ts` 中配置：

```ts
banner: {
  src: "assets/images/neo-tokyo-noir-banner.webp",
  // ...
},
avatar: "assets/images/demo-avatar.png",
```

### 格式建议

- 优先 **WebP**，体积更小
- Banner 建议宽图（如 1920px 宽）
- 封面建议 16:9 或 3:2
- 大图放文章同目录，便于和文章一起管理

### 当前图片目录

```
src/assets/images/          # 全站资源（Banner、头像等）
public/favicon/             # 站点图标
src/content/posts/<文章>/   # 文章专属配图（推荐）
src/content/moments/<碎碎念>/  # 碎碎念配图（推荐）
public/images/              # 可选，静态公共资源
```

## 工作流示例

**写文章：**

```bash
pnpm dev
pnpm new-post 2026/my-first-post/index
# 编辑 index.md，放入 cover.webp、插图
pnpm build
git add .
git commit -m "feat: 新增文章 xxx"
git push
```

**写碎碎念：**

```bash
pnpm dev
pnpm new-moment 2026-07-03-随想
# 编辑 index.md，可选放入配图
pnpm build
git add .
git commit -m "feat: 新增碎碎念"
git push
```
